Project Overview:
StreamingApp is a containerized MERN microservices application deployed using Docker, Jenkins, Amazon ECR, Amazon EKS, and Helm.

Implemented Components:

* GitHub-based source code management
* Docker containerization of frontend and backend services
* Amazon ECR image repositories
* Jenkins CI pipeline
* Amazon EKS Kubernetes cluster
* Helm-based Kubernetes deployment
* MongoDB with persistent EBS-backed storage
* Kubernetes Secrets for sensitive configuration
* Kubernetes service discovery and LoadBalancer exposure
* Horizontal replica scaling validation
* Amazon CloudWatch monitoring and logging
* AWS deployment documentation
* AWS architecture diagram

AWS Configuration:
Region: ap-south-1
